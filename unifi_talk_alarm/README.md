# UniFi Talk Alarm Add-on

Local, authenticated SIP/media service for outbound Home Assistant alarm
calls through a dedicated UniFi Talk extension.

This add-on must be installed and running before the companion integration can
connect. The integration URL is `http://127.0.0.1:8099` unless `api_port` was
changed.

See the add-on **Documentation** tab after installation or the repository's
`INSTALLATION.md` for setup and safety guidance.
